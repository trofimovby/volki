# VOLKI - Домашняя страница

Верстка домашней страницы сайта VOLKI на основе дизайна из Figma.

## 📁 Структура файлов

```
volki/
├── home.html              # Главная HTML страница
├── home-styles.css        # CSS стили с Flexbox
├── home-script.js         # JavaScript для интерактивности
├── figma-exports/         # Экспортированные изображения из Figma
│   ├── hero-bg.png
│   ├── logo.png
│   ├── map-image.png
│   ├── find-territory-bg.png
│   ├── rest-1.png
│   ├── rest-2.png
│   ├── rest-3.png
│   ├── banya-etnos.png
│   ├── banya-shale.png
│   └── banya-znahar.png
└── HOME-README.md         # Этот файл
```

## 🎨 Реализованные секции

### 1. **Hero секция**
- Полноэкранный фон с градиентом
- Логотип VOLKI
- Заголовок "территория вашей силы"
- Описание и CTA кнопка
- Анимация появления элементов

### 2. **Территория VOLKI**
- Двухколоночный layout (текст + карта)
- Интерактивная карта с маркером
- Описание локаций Юхновка и Жуковка

### 3. **Найти свою территорию**
- CTA секция с фоновым изображением
- Градиентный оверлей
- Призыв к действию

### 4. **Как проходит отдых**
- 3 карточки с описанием процесса:
  1. Предвкушение ритуала
  2. Настройка чувств
  3. Трансформация
- Изображения с эффектом zoom при hover
- Нумерация этапов

### 5. **Программы и цены**
- Табы переключения локаций (Юхновка/Жуковка)
- Карточки бань с информацией:
  - Фото бани
  - Название
  - Характеристики (количество бань, вместимость, площадь)
  - Цена
  - Кнопка "Подробнее"
- Hover эффекты на карточках

### 6. **FAQ секция**
- Аккордеон с вопросами и ответами
- Плавное раскрытие/закрытие
- Иконки состояния

## 🎯 Технологии

- **HTML5** - семантическая разметка
- **CSS3** - Flexbox для layout, анимации, градиенты
- **Vanilla JavaScript** - без фреймворков
- **Google Fonts** - Cormorant Garamond, Manrope

## ✨ Особенности

### CSS
- Flexbox для всех layout'ов
- Адаптивный дизайн (desktop, tablet, mobile)
- Плавные transitions и hover эффекты
- Keyframe анимации для hero секции
- CSS переменные для цветов из Figma

### JavaScript
- FAQ аккордеон
- Табы переключения локаций
- Intersection Observer для анимаций при скролле
- Обработчики событий для кнопок

### Цветовая палитра
- `#fbfaf1` - основной фон
- `#2d4939` - темно-зеленый (текст)
- `#9fa874` - оливковый (акценты)
- `#fffdf7` - светлый фон карточек
- `#8c928b` - серый (вторичный текст)

## 🚀 Запуск

Просто откройте `home.html` в браузере:

```bash
open home.html
```

Или через локальный сервер:

```bash
# Python 3
python3 -m http.server 8000

# Затем откройте http://localhost:8000/home.html
```

## 📱 Адаптивность

Страница адаптирована под разные размеры экранов:

- **Desktop** (> 1200px) - полный layout
- **Tablet** (768px - 1200px) - адаптированные колонки
- **Mobile** (< 768px) - одноколоночный layout

## 🎭 Интерактивность

### FAQ Аккордеон
- Клик на вопрос раскрывает ответ
- Автоматическое закрытие других открытых вопросов
- Плавная анимация

### Табы локаций
- Переключение между Юхновка/Жуковка
- Визуальная индикация активной вкладки

### Hover эффекты
- Карточки бань поднимаются при наведении
- Изображения увеличиваются (zoom)
- Кнопки меняют цвет и добавляется тень

### Scroll анимации
- Секции плавно появляются при прокрутке
- Использование Intersection Observer API
